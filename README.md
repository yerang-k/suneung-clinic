# 🧠 승하샘과 함께하는 수능 국어 사고 복원 클리닉 2.0

> 수능 국어 오답의 90%는 지식을 몰라서가 아니라 **시험장 순간의 인지 왜곡과 습관적 선지 독해 오류** 때문입니다.  
> 오프라인 모의고사 풀이 후, **'확신' 문항은 자동 스킵하고 취약 문항만 실제 시험지 원문(PDF)과 함께 AI 소크라테스 인터뷰**로 복원하는 웹 애플리케이션입니다.

---

## 🌟 주요 기능
1. **📄 실물 시험지 원문 PDF 뷰어 탑재**: 확대, 축소, 회전 및 문제 페이지 자동 이동
2. **📋 OMR 일괄 상태 입력 & 스마트 스킵**:
   - 1~45번 전체 문항 상태 입력 (🟢 확신, 🟡 확신 없는 정답, 🔴 오답, ⏱️ 시간부족/찍음)
   - '확신' 문항은 자동 건너뛰고 취약 문항만 순차 인터뷰 큐로 진입
3. **💬 AI 소크라테스 사고 복원 인터뷰**:
   - 정답 비공개 원칙 하에 지문 오독 및 선지 임의 변형 경로 추적
   - 1인칭 사고 요약 ➔ 평가원 함정 설계 분석 ➔ 나만의 단 하나의 행동 원칙 확정
4. **🎯 AI 기출 맞춤 탐색 & 인앱 실전 방어 훈련**:
   - 전체 모의고사 PDF가 모인 구글 드라이브 폴더 연동
   - AI가 최근 3개년 평가원 전 문항 중 동일 함정 구조를 가진 기출 문제 및 PDF 페이지를 자동 탐색하여 뷰어로 즉시 출력
   - 방어 미션에 맞춘 학생의 선지 검증에 대해 Gemini AI 실시간 1:1 코칭 피드백 제공
5. **🔒 교사용 관리자 모드**:
   - 학생 계정 관리 (개별 등록 & CSV 일괄 등록)
   - 시험지 등록 및 실제 원문 PDF 파일 업로드
   - 구글 드라이브 기출 모의고사 마스터 폴더 연동
   - 학생 진단 제출 현황 로그 실시간 열람
